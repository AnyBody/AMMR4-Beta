# Index Finger

:::{anylink-gallery}
:margin:
:::

The index finger model was developed by <a href="https://www.linkedin.com/in/john-wu-490a8821/?isSelfProfile=false" target="_blank" rel="noopener">John Z. Wu</a> (NIOSH, Morgantwon, WV 26505, USA) in 2008.
The model was developed to better understand the muscle forces in the index finger during keyboard key tapping.
The model contains seven muscles/tendons which connect the metacarpal with the three phalangeal finger segments.
This model is a good example of small, stand alone models developed to answer specific research questions.

Please cite the following paper when using or publishing with this model. [^cite_wu]

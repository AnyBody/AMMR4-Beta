# Simple Lower Extremity Model


:::{anylink-gallery}
:margin:
:::


This model is a lower-extremity variant of the <a
href="Plug-in-gait_Simple_FullBody.html" target="_blank" rel="noopener">Simple
Full-Body Model</a> using the Plug-in-Gait marker protocol and walking data
recorded on three type 4 force platforms. The `INCLUDE_UPPERBODY` switch is set
to `OFF`, so the model focuses on the lower extremities and trunk while
retaining the same general workflow as the full-body example.

The model is fairly simple and a good starting point for lower-extremity
analyses. For analyses involving many trials or subjects, see the <a
href="Plug-in-gait_MultiTrial_StandingRef.html" target="_blank"
rel="noopener">multi-trial MoCap example</a>.
